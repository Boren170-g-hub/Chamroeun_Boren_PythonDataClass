# PUC Python for Data

Course notebooks and materials for data analysis and visualization.

## Project structure

- `notebooks/` — course Jupyter notebooks
- `data/raw/` — original datasets
- `data/processed/` — cleaned or transformed datasets
- `figures/` — charts and other exported figures

## Setup

The project uses the `venv/` virtual environment and dependencies listed in
`requirements.txt`. In VS Code, select the Python interpreter from `venv/` as
the notebook kernel.

The virtual environment and Jupyter checkpoint files are excluded from Git.
